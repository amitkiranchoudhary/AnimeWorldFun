# Anime World Fun

A fan-made anime site: find any anime, see where to watch it and in which language
(sub or dub), track what you've watched, and read the owner's blogs.

The website lives in [`web/`](web/) — see [web/README.md](web/README.md) to run it.

The original Vite + Express demo is preserved under the `v1-demo` tag.
